声序 SONORA · 网页 UI 交互原型
2026-10-30

打开方式
1. 在线版本使用最终交付的私有原型网址。
2. 离线查看：双击 offline/sonora-ui-prototype.html。此文件已内嵌所有代码与样式，不依赖网络字体。
3. 开发：dist/index.html + styles.css + app.js；使用任意静态 HTTP 服务器。

可真实操作
- 解码本地音频、播放、循环、波形选择；文件字节不上传。
- 内置合成分轨试听、音量、静音、独奏；候选B是滤波对照。
- 歌词字符数提示、示例音符/曲线编辑与参数记录。
- 音频裁剪与总线增益，导出16-bit PCM WAV。
- 配方JSON导入导出、候选状态、撤销；音频需另外保留或重新链接。

演示范围
- AI分离、F0检测、歌词识别、VC/SVS、参数搜索、专业后期和任务进度是交互模拟。
- 未接入真实推理器。示例曲线/候选不能视为用户音频的分析或模型效果。
- 网页不会加载用户模型权重、录制麦克风、安装虚拟声卡或扫描本地服务。

浏览器原型上限
单个输入文件64MB、10分钟、双声道；解码PCM上限128MiB。
显示的是浏览器解码采样率，可能与文件容器采样率不同。
实际WAV导出按解码采样率、16bit PCM；正式版格式选择仅记录配方。
工程配方包含编辑设置但不包含源音频。刷新不会持久保存源文件。

建议演示路径
导入与诊断 → 歌曲翻唱 → 人声整理 → 音高与歌词（局部复核/手动编辑） → 声音转换（演示候选） → 混音 → 导出。
改词：音高与歌词 → 歌词与音符 → 编辑新词 → 选择导唱或SVS路线。
已训练VC模型不等于歌声合成声库，新歌词需要新的演唱内容。

验证记录
- JavaScript语法检查通过。
- 浏览器验证六步导航、模式切换、歌词提示、音高修复与候选队列。
- 合成WAV导出24.0秒、32000Hz、2声道、16bit；重新导入测量44.1kHz解码结果。
- 2–6秒选区导出经WAV解析实测4.0秒。
- 390px窄屏页面视觉检查。
- 未进行神经模型音质、显存或延迟实测。
