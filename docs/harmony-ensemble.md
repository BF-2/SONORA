# 二级和声增强分离

界面在“两级分离”的“主唱 / 和声推理算法”中提供“增强和声分离 · 双模型与时间错位融合”。新工程默认采用增强模式，已有工程显式保存的单模型设置继续按其配置执行。输出仍为 Main 与 Follower，分离版本列表记录两套模型的身份。

## 推理与融合

1. 使用当前主模型和另一套已安装的 Karaoke 模型，分别校验权重、配置、原生输出名称与 lead/backing 语义。两套权重需要不同，工作采样率需要一致。
2. 每套模型进行三次预测，时间偏移固定为 0、113、227 ms，其中一次交换左右声道。预测后还原偏移和声道顺序，再取波形均值。
3. 按辅助模型权重融合两套 Main 估计，默认权重 0.5。时间错位平均用于减少窗口位置敏感性，多模型波形平均用于融合不同权重的预测。这些设计参考了 Demucs 的 shift trick 和原分离训练项目的 ensemble 实现。[Demucs](https://github.com/facebookresearch/demucs)，[波形融合说明](https://github.com/ZFTurbo/Music-Source-Separation-Training/blob/main/docs/ensemble.md)
4. 默认启用 0.8 强度的立体声保护。先通过预测 Main 的 mid/side 能量比估计其居中程度。当神经网络预测的伴唱与原混合人声的 side 信号具有稳定相关性时，用整个片段估计的声像比例恢复伴唱。声像过窄或空间估计与神经模型明显分歧时，保留模型估计。其它立体声输入使用平滑时频互相关估计，只在高置信度的频段融合空间信息。单声道输入采用神经模型融合结果。
5. 可选“伴唱残留抑制”，默认 0。它使用两模型残差能量形成平滑且左右声道共享的掩码，增大时会同时改变弱伴唱保留量。
6. 最终 Follower 使用输入与最终 Main 的差值构造，并验证两者的和。保留浮点电平、声道、采样数与原时间轴。混合一致性是信号约束，其理论参考见一致性约束论文。[Wisdom 等，2018](https://arxiv.org/abs/1811.08521)

参数范围均为 0–1。两个模型顺序加载，释放前一个模型后再加载后一个，推理执行六遍。模型缺失、语义不符、采样率不一致、哈希变化或输出无效均返回错误。

## 缓存与追溯

`workers/separation/ensemble.py` 实现错位推理、融合与空间保护，`workers/separation/run.py` 复用原模型加载与输出协议。编排缓存键同时包含两模型/config 哈希、算法代码哈希、融合比例、空间保护、残留抑制、窗口和步进。产物元数据记录各模型 ID/hash、偏移采样数、实际参数与重建误差。

已有单次推理和三次反相/换声道平均可用于同输入对比。新结果保存为另一套分离版本，后续转换直接使用选定源轨及缓存。

## 本机对比

`scripts/verify_harmony_ensemble.py` 使用本地真实权重，比较旧单次算法与增强算法。受控样本由两条已知的合成歌声构建，其中一条调整音高和时间，分别构造居中与宽声像混合。以已知 Follower 波形计算直接 SDR。

| 已知分轨样本 | 旧算法 Follower SDR | 增强算法 Follower SDR | 差值 |
| --- | --- | --- | --- |
| 居中双声部 | -4.75 dB | -3.59 dB | +1.16 dB |
| 宽声像双声部 | 14.69 dB | 22.96 dB | +8.26 dB |

居中样本的绝对分离质量仍较低，说明两条同类声线同时居中时存在明显的声部混淆。声像保护的效果依赖居中主唱与可辨识的伴唱空间信息。不同编曲仍需试听选择参数。

另对 12 秒真实歌曲人声运行两种算法，增强结果的 Main + Follower 最大重建误差为 `5.96e-8`。最后一轮单模型耗时约 5.98 秒，增强模式约 13.25 秒。真实歌曲缺少独立真值分轨，保留两组音频供听感比较。

对比音频及机器可读结果位于 `runtime/editor-followup/harmony/`。`scripts/verify_editor_audio.py` 进一步验证 API 的双模型元数据、第二次相同分离的缓存命中，以及实际 RVC 输出中全部无音高区域的精确静音。
